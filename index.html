Hire Me For

Explore the key roles where I can leverage my data analytics, machine learning, and frontend skills to drive business value.

Data Analyst

Using my expertise in SQL (queries, joins, CTEs), Python (Pandas/Numpy), and Advanced Excel, I clean complex data, perform EDA, and extract insights. My ability to translate raw numbers into actionable business decisions makes me a strong fit.

BI Analyst

Equipped with Power BI (DAX, modeling) and Tableau, I build enterprise-grade interactive dashboards and KPI reports. I design clear visual layouts that let stakeholders track metrics instantly.

Data Scientist

Combining my mathematical foundations with Python statistical libraries and Machine Learning algorithms, I build predictive models, run A/B tests, and structure unstructured datasets to solve predictive business cases.

Machine Learning Engineer

I design, train, and deploy regression and classification models using Python machine learning frameworks (Scikit-Learn). I focus on model optimization, evaluation metrics (accuracy, F1-score), and production readiness.

Product Analyst

Using custom data telemetry and funnel analytics, I track user retention and behavior. I run regression analysis to understand feature usage trends and perform A/B testing evaluation to guide product updates.

Data Engineer

Leveraging my Web Scraping skills (BeautifulSoup, Scrapy, Selenium) and ETL frameworks, I automate large-scale data ingestion and orchestrate pipelines, delivering clean, structured data to warehouses.
